# 세종대왕을 이겨라! 훈민정음 끝말잇기 👑

세종대왕과 끝말잇기를 겨루는 브라우저 게임입니다. 5턴 동안 살아남으면 승리합니다.

**바로 하기:** https://bbannggji1220-bot.github.io/sejong-wordchain/

## 규칙
- 한 턴에 10초 안에 단어를 올려야 합니다.
- 앞 단어의 끝 글자로 시작해야 합니다. 두음법칙(ㄹ→ㄴ/ㅇ, ㄴ→ㅇ)을 인정합니다.
- 국립국어원 표준국어대사전에 실린 두 글자 이상 명사만 인정합니다.
- 이미 나온 단어를 다시 쓰면 탈락합니다.

## 특징
- `index.html` 파일 하나로 동작하며, 외부 API나 API 키가 필요 없습니다.
- 인터넷이 없어도 동작합니다. 폭죽 효과는 인터넷이 있으면 canvas-confetti를, 없으면 내장 효과를 씁니다.
- 표준국어대사전 명사 212,933개가 내장되어 있습니다.
